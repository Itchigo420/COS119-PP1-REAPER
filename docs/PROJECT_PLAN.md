# Project Plan

## Concept
REAPER-inspired C++ console application for monitoring and managing simulated system components.

## Course Skills
- Object-oriented programming
- Vectors and data structures
- Pointers and references
- Dynamic memory management
- File I/O
- Code organization and refactoring
- Testing and debugging
- Git/GitHub workflow

## Initial Milestones
1. Environment and repository setup
2. Application skeleton and core classes
3. System-status features
4. File persistence
5. Pointer/memory-management feature
6. Testing and refactoring
7. Final documentation
