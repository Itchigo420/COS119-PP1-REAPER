# COS119 PP1 - REAPER C++

A C++ console application developed for Project & Portfolio I.

## Course Workflow

Development follows the course workflow:

Backlog -> To Do -> In Progress -> Done

Code changes are developed on the `dev` branch and merged into `main` through pull requests.

## Project Goal

Build a REAPER-inspired system monitoring and management console that demonstrates object-oriented programming, vectors, pointers/references, memory management, file I/O, testing, debugging, and iterative development.

## Repository Structure

- `/dev` - development source and project files
- `/docs` - planning and documentation
- `/images` - screenshots added later in the course
